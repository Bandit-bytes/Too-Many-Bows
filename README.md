# Too Many Bows

Adds a large collection of unique bows, projectiles, accessories, and abilities to Minecraft.

**Download:** [CurseForge](https://www.curseforge.com/minecraft/mc-mods/too-many-bows)

*Minecraft mod — not affiliated with Mojang or Microsoft.*

| Loaders | Fabric, NeoForge |

- **Fabric:** Fabric API, Architectury API, Trinkets Updated
- **NeoForge:** Architectury API, Curios API

## Building

Requires JDK 25.

```sh
./gradlew build
```

Built jars end up in `fabric/build/libs` and `neoforge/build/libs`.
